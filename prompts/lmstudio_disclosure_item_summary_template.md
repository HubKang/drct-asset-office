# 작업
아래 DART 공시 1건을 투자 관점에서 정확히 요약하라.

규칙:
- 제공된 공시 제목, 공시 유형, 공시일만 근거로 작성한다.
- 모르는 내용은 "원문 확인 필요"라고 작성한다.
- 매수/매도 판단을 하지 않는다.
- 투자자가 이해하기 쉽게 3~5문장으로 작성한다.
- JSON을 출력하지 않는다.
- Markdown을 출력하지 않는다.
- 코드블록을 출력하지 않는다.
- Thinking Process, Analysis, Reasoning 등 사고 과정을 출력하지 않는다.
- 요약문만 출력한다.
- 마지막 문장은 완성된 문장으로 끝나야 한다.

공시 제목:
{{disclosure_title}}

공시 유형:
{{disclosure_type}}

공시일:
{{disclosed_at}}

출력:
투자 관점 요약문만 작성한다.
