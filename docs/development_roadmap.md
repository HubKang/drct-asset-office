# 개발 로드맵

## 단계별 진행 계획
1. 기반 구성: 폴더/설정/문서 표준화
2. 공통 코어: 설정, 로깅, DB 연결 레이어 정리
3. 수집 체계: Collector 구조와 수집 스케줄 설계
4. 저장 체계: SQL 스키마/마이그레이션 규칙 정립
5. 도메인 체계: Entities/Repositories/Services 계층 확장
6. API 체계: FastAPI 기반 운영 API 구현
7. UI 체계: 사용자 샘플 UI 기준 화면 구성
8. 리포트 체계: 일간/기업/리스크 리포트 자동화
9. Agent 체계: 분석/리스크/지식 Agent 협업 흐름 정착
10. 운영 체계: 안정화, 회고, 규칙 고도화

## 완료 기준
- 각 단계 종료 시 문서와 실행 산출물 동기화
- 민감 데이터 및 원천 데이터 Git 제외 원칙 준수
