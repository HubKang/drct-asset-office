# 매매훈련 선택 종목 가격 수집

## 목적

종목매매 훈련 시작 모달에서 선택한 종목 한 개의 일봉 가격과 기술지표를 다른 화면으로 이동하지 않고 갱신한다. 대상은 요청의 `stock_id` 한 개로 고정되며 관심종목·종목트래킹 등록 여부와 무관하다.

## 수집 모드

- `RECENT_7D` / `selected_recent_7d`: 서울 기준 오늘부터 최근 7일 범위만 요청한다. 저장 데이터가 없어도 전체 백필로 전환하지 않으며, 키움 일봉 페이지는 날짜 범위를 벗어나면 중단한다.
- `FULL` / `selected_full`: 프로젝트의 기존 전체 수집 정책과 같은 최근 2년 지원 범위를 페이지 조회해 upsert한다. 실행 전 사용자 확인을 받는다.

두 모드 모두 기존 일봉을 삭제하지 않고 `(stock_id, trade_date, source)` 기준 upsert를 사용한다. 가격 저장 후 이동평균선과 기존 기술지표 계산 서비스를 실행한다. 시장지표, 재무, 투자자 수급, 뉴스, 공시, 테마 및 평가 수집은 실행하지 않는다.

## 화면 동기화

응답은 수집·저장·기술지표 건수와 저장된 전체 가격 건수, 최초일, 최근일을 반환한다. 종목 목록의 날짜는 수집 실행 시각이 아니라 저장 가격의 최초·최종 거래일인 `가격 범위`로 표시한다. 모달은 해당 종목 카드와 가격 데이터 패널을 즉시 갱신한다. 초기자금, 수수료율, 표시 일수, 이동평균선 입력은 보존한다. 종료일이 비어 있거나 수집 전 최근일과 같을 때만 새 최근일로 이동하고, 시작일은 새 범위 밖일 때만 최초일로 보정한다.

수집 중에는 종목 변경, 두 수집 버튼, 검색 및 훈련 시작을 막아 중복 실행과 결과 오적용을 방지한다.

## 오류와 로그

- 없는 종목: HTTP 404
- 잘못된 모드: HTTP 400
- 외부 가격 응답 실패: 기존 데이터 유지, 결과의 `success=false`
- 가격 저장 후 기술지표 계산 실패: 가격은 유지하고 `partial=true`, `technical_indicator_error` 반환

시작과 완료 로그는 `[TRADE TRAINING PRICE COLLECT]`, `[TRADE TRAINING PRICE COLLECT DONE]` 접두어를 사용하며 항상 `target_count=1`을 기록한다. 원천 API 응답이나 재현 가능한 시계열 JSON은 별도로 저장하지 않는다.
