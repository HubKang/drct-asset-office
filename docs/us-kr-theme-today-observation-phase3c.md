# 한미테마비교 Phase 3-C — 오늘의 연계 관찰

## 목적

직전 미국 실제 거래일의 연결 테마 상태와 과거 동일 조건에서 관찰된 국내 D0 반응을 한 화면에서 비교한다. 이 화면은 예측·추천·매매 신호가 아니라 현재 조건과 과거 표본을 정리하는 관찰 화면이다.

## 데이터 및 계산 정책

- 대상: `us_kr_theme_links`의 활성 1:1 연결만 사용한다.
- 미국 기준일: `us_theme_daily_returns.trade_date`의 최신 실제 거래일이다.
- 국내 대상일: Phase 3-B와 동일한 거래일 매칭 함수로 미국 기준일 이후 첫 실제 KRX 거래일을 찾는다. 최대 휴장 간격은 7일이다.
- 분석 기간: 최근 60/120/250쌍 또는 전체를 지원한다.
- 미국 지표: 테마강도 또는 단순등락률을 선택한다.
- 현재 조건: 최신 미국 지표를 `> 0`, `>= +1`, `>= +2`, `>= +3`, `< 0`, `<= -1`, `<= -2`, `<= -3` 구간으로 판정한다.
- 과거 반응: Phase 3-B의 Pair Matching과 Threshold 집계 함수를 그대로 사용해 동방향 반응률, 표본 수, 국내 평균 D0를 계산한다.
- 최신 미국 값이 없으면 0으로 대체하지 않고 데이터 없음으로 표시한다. 실제 값이 0이면 유효한 중립 관찰로 처리한다.
- 요청 시 일괄 조회 후 메모리에서 계산하며 Snapshot, Ranking JSON, Pair JSON, 분석 JSON을 저장하지 않는다.

## API

`GET /us-kr-theme-links/today-observation`

Query:

- `window`: `60 | 120 | 250 | 0` (`0`은 전체)
- `us_metric`: `theme_strength | simple_return`

응답은 날짜, 연결/관찰 가능/데이터 없음/상승/하락 요약과 연결별 최신·전일 미국 값, 변화폭, 확산도, 현재 Threshold, 동일 조건 표본·반응률·평균 국내 D0를 명시적 필드로 반환한다.

## 화면 동작

- 기존 한미테마비교 탭 UI의 `오늘의 연계 관찰` Placeholder를 실제 화면으로 교체했다.
- Toolbar에서 분석 기간, 미국 기준 지표, 관찰 방향을 선택하고 새로고침할 수 있다.
- 방향 정렬:
  - 상승: 최신 미국 값 내림차순
  - 하락: 최신 미국 값 오름차순
  - 전체: 최신 미국 값 절댓값 내림차순
  - 동률은 과거 반응률, 표본 수 순으로 정렬하며 데이터 없음은 항상 하단에 둔다.
- 상세 분석은 같은 연결 테마와 `window`, `metric`, `direction` URL 상태를 유지한 채 Phase 3-B 화면으로 전환한다.
- 좁은 화면에서는 표 행을 카드형으로 전환한다.
