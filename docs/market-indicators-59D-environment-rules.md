# 59-D 시장환경 해석 룰 및 요약 카드

## 변경 파일
- frontend/src/utils/marketEnvironmentRules.ts
- frontend/src/pages/MarketIndexesPage.tsx
- frontend/src/index.css

## UI 위치
시장 지표 관리 화면에서 기존 상단 요약 카드 아래, 지표 그룹 필터 위에 `시장환경 해석` 영역을 추가했다.

## 카드 구성
기본 6개 카드로 구성한다.
- 주식시장 흐름
- 환율 환경
- 금리 환경
- 물가 환경
- 경기 심리
- 위험회피 흐름

각 카드는 title, tone badge, headline, description, evidence chips를 표시한다.

## 룰 함수
`buildMarketEnvironmentInsights({ marketIndexes, marketIndicators })`에서 rule-based 해석을 생성한다.
반환 타입은 `MarketEnvironmentInsight[]`이며 향후 대시보드, 복기, 매매훈련 요약에 재사용할 수 있다.

## 주요 룰
- 주식시장: KOSPI/KOSDAQ 5일 수익률 조합으로 반등, 약세, 대형주 우위, 코스닥 상대 강세를 해석한다.
- 환율: USD_KRW 변화율이 +0.3% 이상이면 원화 약세 부담, -0.3% 이하이면 부담 완화 가능성으로 표시한다.
- 금리: KTB_10Y 변화폭을 기준으로 장기금리 상승/하락 환경을 해석하고 bp를 evidence에 표시한다.
- 물가: CPI MoM/YoY와 PPI YoY를 참고해 물가 부담 또는 완화 가능성을 표시한다.
- 경기: CSI/BSI_MANUFACTURING을 기준선 100과 비교해 경기 심리 상회/하회/혼재를 표시한다.
- 위험회피: GOLD_KRX 20일 수익률과 KOSPI/KOSDAQ 흐름 조합으로 위험회피 또는 위험선호 흐름을 참고 표시한다.

## 데이터 부족 처리
필수 지표가 없거나 최신값이 없으면 neutral tone의 `데이터 확인 필요` 카드로 표시하며 화면 오류가 발생하지 않도록 처리했다.

## 문구 원칙
매수, 매도, 추천, 확정 같은 투자판단 문구는 사용하지 않았다. 모든 문구는 시장환경 참고 수준으로 제한했다.


## 59-D-1 다중 관점 보강

시장환경 해석 카드가 단일 결론처럼 보이지 않도록 `perspectives` 필드를 추가했다. 각 카드는 최대 3개의 관점을 표시한다.

- 주식시장 흐름: 긍정 관점, 주의 관점, 대형주/코스닥 상대 강도 확인 포인트
- 환율 환경: 원화 약세 부담, 수출기업 환산 실적 가능성, 수출 업종 강도 확인 포인트
- 금리 환경: 장기금리 하락의 할인율 부담 완화, 경기 둔화 우려 가능성, 성장 업종 상대 강도 확인 포인트
- 물가 환경: CPI/PPI 상승 부담, 물가 둔화의 금리 인하 기대 가능성, CPI/PPI 방향성 확인 포인트
- 경기 심리: CSI 기준선 상회, BSI 기준선 하회, 소비/제조업 신호 동행 여부 확인 포인트
- 위험회피 흐름: 금현물 상승과 주식시장 약세의 위험회피 가능성, 인플레이션 헤지 가능성, 환율/금리/주식시장 동시 확인 포인트

문구는 가능성, 부담 요인, 확인 필요, 참고할 수 있음 중심으로 유지했고 투자 추천 표현은 사용하지 않았다.
