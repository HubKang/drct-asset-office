# 매매훈련 캘린더 수익률 색상 기준

## 목적
월간 훈련 캘린더와 월간 성장 추이 그래프의 색상을 훈련점수가 아니라 총 수익률 기준으로 표시한다.

## 기준
- 총 수익률 > 0: 빨강 계열
- 총 수익률 < 0: 파랑 계열
- 총 수익률 = 0 또는 값 없음: 중립 회색

## 단계
절댓값 기준으로 농도를 나눈다.

- 0% 초과 ~ 3% 미만: pale
- 3% 이상 ~ 10% 미만: soft
- 10% 이상 ~ 30% 미만: medium
- 30% 이상: strong

## 적용 범위
- 캘린더 날짜 셀 배경: `total_return_rate`
- 월간 성장 추이 막대 색상: `total_return_rate`
- 월간 성장 추이 막대 높이: 기존처럼 `training_score`
- 총 수익률 텍스트: 양수 빨강, 음수 파랑, 0 회색
