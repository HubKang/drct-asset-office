# 시장테마 수급추이 히트맵 4-A단계

## 목적과 기존 화면 관계

`시장 테마 관리 > 테마 관리`에 기존 `테마등락추이`와 독립된 `테마수급추이` 탭을 추가한다. 가격 히트맵의 필터·날짜 열·테마 행·셀 클릭 문법을 유지하면서, 저장된 종목 수급이 최근 거래일에 어느 테마로 유입되거나 유출됐는지 비교한다. 기존 가격 히트맵과 선그래프는 변경하지 않는다.

이번 단계는 일별 탐색 MVP다. 기간 누적 순위, 수급 점수, 선행·동행·후행 판정, 자동 유형 분류, GPT 해석 및 추천은 포함하지 않는다.

## 화면 구조

- 공통 필터: 기준일, 테마그룹, 테마 검색, 상위 N, 저장 데이터 새로고침
- 투자주체: 외국인, 기관, 외국인+기관, 개인, 프로그램
- 표시 지표: 수급 강도, 순매수 금액, 연결종목 확산도
- 종목 반영 기준: 중복테마별 1/n, 중복테마별 1
- 상단 카드: 오늘 유입 1위, 최근 5일 누적 1위, 연결종목 확산도 1위, 순매수 지속 1위
- 본문: 최근 거래일 날짜 열과 테마 행으로 구성된 일별 히트맵
- 행 요약: 최근 20거래일 누적 금액, 기간 수급 강도, 최신 확산 종목 수, 현재 연속 흐름, 완전성
- 셀 도움말: 순매수, 강도, 연결종목 확산도, 테마등락률, 거래대금, 상위 기여 종목 3개, 완전성, 종목 반영 기준

상단 카드를 클릭하면 해당 테마 행으로 이동해 잠시 강조한다. 셀을 클릭하면 기존 테마 상세 Drawer를 클릭 날짜로 열며, 선택 투자주체 카드를 강조한다. 히트맵이 `FRACTIONAL`이고 Drawer가 `FULL`인 경우 두 기준을 Drawer에 함께 명시한다. 해당 날짜의 레거시 테마등락 스냅샷이 없어도 현재 활성 연결과 저장된 가격·수급으로 읽기 전용 상세를 구성하므로 과거 수급 셀에서 종목 목록이 비지 않는다.

## 투자주체 계산

- `INDIVIDUAL`, `FOREIGN`, `INSTITUTION`, `PROGRAM`은 저장된 직접 수집 금액을 사용한다.
- `FOREIGN_INSTITUTION`은 외국인과 기관 값이 모두 존재할 때 두 값을 합산한다. 어느 한쪽이 결측이면 합산값도 결측이다.
- 개인을 잔차로 계산하지 않는다.
- 프로그램은 별도 매매 방식 수급이다. 투자주체 합계에 포함하지 않으며 외국인·기관 거래와 일부 중복될 수 있음을 화면에 안내한다.

## FULL·FRACTIONAL 귀속

집계 기준은 항상 조회 시점의 현재 활성 테마 연결이다. 과거 연결 관계를 추정하지 않는다.

- `FULL`: 해당 테마의 활성 연결 종목 금액과 거래대금을 100% 반영한다. 기존 3단계 상세와 동일하다.
- `FRACTIONAL`: 종목 금액과 거래대금을 그 종목의 현재 활성 연결 테마 수로 각각 나눈다. 같은 비율을 분자와 분모에 적용한다.

분할값은 화면용으로 계산하며 DB에 저장하지 않는다.

## 지표 공식

수급 강도:

`선택 주체 귀속 순매수 금액 ÷ 동일 귀속 테마 거래대금 × 100`

거래대금이 없거나 0이면 강도는 `null`이다. 가격 원천의 거래대금은 저장된 테마 종목 일별 원 단위 값을 우선 사용하고, 없을 때 공통 일봉의 백만원 단위 값을 원으로 환산한다.

연결종목 확산도:

`순매수 금액이 양수인 종목 수 ÷ 선택 주체 데이터가 존재하는 종목 수 × 100`

실제 0은 데이터 보유 종목과 0 종목 수에 포함한다. 결측은 분모와 합계에 포함하지 않는다.

최근 20일 기간 수급 강도:

`20거래일 누적 순매수 금액 ÷ 20거래일 누적 거래대금 × 100`

일별 강도의 단순 평균을 사용하지 않는다.

연속성은 최신일부터 역순으로 동일 부호 금액을 센다. 0 또는 결측일은 연속성을 끊고 휴장일은 날짜 목록에 없으므로 영향을 주지 않는다.

## 색상

- 수급 강도: `-10, -7, -5, -3, 0, +3, +5, +7, +10%` 고정 구간. 양수는 붉은색, 음수는 푸른색이다.
- 순매수 금액: 응답 유효 절대값의 95 percentile을 색상 상한으로 사용해 극단값의 영향을 줄인다. 셀 표시 금액은 바꾸지 않는다.
- 연결종목 확산도: 0~30 강한 음수, 30~40 약한 음수, 40~60 중립, 60~70 약한 양수, 70~100 강한 양수다.
- `null`은 비활성 배경과 `-`로 표시한다.

## 데이터 완전성

`선택 주체 데이터 종목 수 ÷ 현재 활성 연결 종목 수`

- `ENOUGH`: 90% 이상
- `PARTIAL`: 60% 이상 90% 미만
- `INSUFFICIENT`: 0% 초과 60% 미만
- `EMPTY`: 0%

API는 양수·음수·0·결측 종목 수를 별도로 반환한다.

## API

`GET /external/kiwoom/market-themes/flow-trend`

파라미터:

- `end_date`, `recent_days`(1~60)
- `actor`: `FOREIGN | INSTITUTION | FOREIGN_INSTITUTION | INDIVIDUAL | PROGRAM`
- `metric`: `FLOW_STRENGTH | NET_AMOUNT | BREADTH`
- `attribution`: `FRACTIONAL | FULL`
- `theme_group_id`, `search`, `limit`
- `refresh`: 메모리 캐시를 비우고 저장 DB를 다시 읽음

응답은 요청 메타, 실제 거래일, 상단 카드, 테마별 20일 요약, 일별 셀, 기여 종목, 성능 정보를 포함한다. 외부 Kiwoom provider를 호출하지 않는다.

## N+1 방지와 캐시

냉간 조회는 최대 네 쿼리로 처리한다.

1. 현재 활성 테마-종목 연결 전체 및 종목별 활성 테마 수
2. 조회 기준일 이하 최근 공통 거래일
3. 대상 고유 종목의 기간 수급·거래대금
4. 대상 테마의 기간 일별 등락률

테마·날짜·종목별 반복 쿼리와 단일 종목 차트 API 재호출은 없다. 동일 파라미터 결과는 프로세스 메모리에 60초 보관한다. 캐시는 DB에 저장하지 않으며 다음 동작에서 무효화한다.

- 테마 생성·수정·비활성화
- 테마 연결 추가·수정·해제·재연결
- 테마 등락률 또는 가격·수급 갱신 완료
- 수급추이 탭의 저장 데이터 새로고침

프런트는 60초 메모리 캐시, `AbortController`, 요청 순번을 사용한다. 빠른 필터 변경 시 취소된 응답이나 오래된 응답이 최신 선택을 덮어쓰지 않는다.

## 성능 및 실데이터 검증

2026-07-31 저장 데이터, 최근 30거래일 요청(저장 데이터상 27거래일), 외국인·수급 강도·중복테마별 1/n 조건에서 측정했다. 상위 20개 냉간 HTTP 응답은 367ms(서비스 집계 183ms), 4개 쿼리, 약 367KB였다. 동일 조건 캐시 응답은 175ms, DB 쿼리 0회였다. `limit`을 생략한 전체 31개 테마 냉간 응답은 413ms(서비스 집계 156ms), 4개 쿼리, 약 565KB였다. 응답의 `performance`에는 쿼리·집계·JSON 직렬화·전체 서비스 시간과 응답 크기를 기록한다.

AI반도체/HBM의 2026-07-31 `FULL` 외국인 집계는 다음과 같이 기존 3단계 당일 상세와 일치한다.

- 순매수: 5,839,637,000,000원
- 거래대금: 33,231,784,000,000원
- 수급 강도: 17.5724%
- 완전성: 13/13종목

`FRACTIONAL`은 같은 날짜에 분자와 분모가 모두 현재 활성 연결 수로 분할된다. 프로그램은 별도 결과이며 결측은 0으로 바뀌지 않는다. 조회 과정에서 신규 테이블, 파생 JSON 저장, 외부 수집 또는 전체 145개 종목 수집을 수행하지 않는다.

## 후속 4-B단계

5D·1M·3M·6M 기간별 누적 순매수, 수급 강도, 연결종목 확산도, 기간 수익률, 완전성 정렬과 상세 연결을 별도 기간 순위 화면으로 확장한다.
