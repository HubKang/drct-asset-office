# 매매훈련 기간별 전체 추세 차트

## 화면 구조

기술분석 상세 Drawer는 탭 없이 다음 순서로 표시한다.

1. 1M·3M·6M·1Y·ALL 기간 버튼
2. 종합·추세·이동평균·거래량·가격 위치 compact 카드
3. 선택 기간 전체 캔들·거래량·MA20·MA60·회귀 추세선·상하단 채널
4. 짧은 해설과 최대 3개의 다음 확인 항목
5. 메모리 전용 설정 및 닫기

메인 매매훈련 차트의 최근 80봉 자동 추세분석은 그대로 유지한다. 상세 차트는 해당 80봉을 확대하지 않고 선택 기간 전체를 독립 계산한다.

## 데이터 경계

- 조회 기준은 항상 `trade_date <= training_as_of_date`이다.
- 차트와 분석 입력은 `training_start_date <= trade_date`로 한 번 더 제한한다.
- ALL은 훈련 시작 캔들부터 현재 훈련 기준일 캔들까지다.
- 회귀선과 채널은 화면에 표시된 전체 캔들로 계산한다.
- 상세 응답은 전환 이벤트 이력과 5개 기간 요약 묶음을 반환하지 않는다.

## 저장 정책

분석 결과, 차트 좌표, 기간 선택, 설정 override는 DB·localStorage·sessionStorage에 저장하지 않는다. 요청별 계산값과 기존 5분 서버 메모리 캐시만 사용한다.

## 성능 기준

캔들은 SVG `viewBox`에 fit-to-width로 배치하며 가로 스크롤을 만들지 않는다. 500봉 이상은 dense 표시를 적용한다. 기간 전환은 기존 AbortController와 요청 순번 보호를 사용하여 마지막 응답만 화면에 반영한다.
