# 시장 테마 현재 강도 순위

## 목적

테마 등락 추이의 기본 순위를 단순 30일 누적 등락률에서 **최근 상승의 크기, 지속성, 가속도, 신선도**를 함께 반영한 현재 강도 순위로 변경한다. 기존 30일 누적 기준은 비교용 정렬로 유지하며, 히트맵 셀의 일별 평균 등락률 계산은 변경하지 않는다.

## 점수 산식

현재 강도 점수는 최근 실제 관측값을 기준으로 0~100점으로 계산한다. 관측값이 5개 미만이면 점수를 계산하지 않고 `데이터 부족`으로 표시한다.

```text
현재 강도 = 최근 10일 가중수익률 백분위 × 45%
          + 상승 지속성 × 25%
          + 단기 모멘텀 백분위 × 20%
          + 신선도 × 10%
          - 정체 패널티(최대 20점)
```

- 최근 10일 가중수익률: 오래된 값부터 1~10의 선형 가중치를 적용한 평균 등락률이다.
- 상승 지속성: 최근 10개 관측일 중 플러스 등락일의 비율이다.
- 단기 모멘텀: 최근 5개 관측일 평균과 직전 5개 관측일 평균의 차이다.
- 신선도: 마지막 의미 있는 상승 충격(일등락률 3% 이상) 이후 경과한 관측일 수를 감점 없이 0~100으로 환산한다.
- 백분위는 동일 필터에 포함된 전체 테마를 대상으로 평균 순위 방식으로 계산한다.
- 최종 점수는 0~100 범위로 제한한다.

## 정체 패널티

아래 조건별로 5점씩, 최대 20점을 차감한다.

- 30일 누적 등락률이 양수이면서 최근 5일 누적 등락률이 음수
- 최근 10일 상승 지속성이 40% 미만
- 최근 5일 누적과 직전 5일 누적의 차이가 음수
- 30일 누적 등락률이 표시 기간 내 최고점보다 8%p 이상 낮음

## 상태 분류

상태는 아래 우선순위대로 한 개만 부여한다.

1. `FADING` / 소멸: 강도 30점 미만, 최근 5일 누적 음수, 지속성 40% 미만
2. `SLOWDOWN` / 둔화: 30일 누적이 양수이고 최근 5일 누적 음수·모멘텀 음수·지속성 50% 미만 중 하나 이상 충족
3. `IGNITION` / 점화: 최근 5일 누적과 모멘텀이 양수이고 직전 5일 누적이 0 이하
4. `PERSISTENT` / 지속: 강도 60점 이상, 최근 5일 누적 0 이상, 지속성 60% 이상
5. `NEUTRAL` / 중립

## 화면 표시

- 기본 정렬은 `현재 강도순`이다.
- `30일 누적순` 버튼으로 기존 순위를 즉시 확인할 수 있다.
- 행에는 `강도 N점 · 30일 ±N.NN% · 상태`를 표시한다.
- 거래대금은 행의 툴팁에 유지한다.
- 요약 카드는 현재 강도 1위, 30일 누적 1위, 거래대금 1위, 상승 지속성 1위를 보여준다.
- 선형 차트의 테마 순서는 선택한 정렬 기준을 따른다.

## API

`GET /api/external/kiwoom/market-themes/returns/range`

- `sort_by=CURRENT_STRENGTH` (기본값)
- `sort_by=ROLLING_30D_RETURN`

계산에 필요한 이력을 확보하기 위해 요청 시작일보다 최대 59일 앞선 데이터까지 조회하되, 응답의 날짜 열과 히트맵 값은 사용자가 요청한 표시 구간으로 제한한다. 요약과 순위는 화면의 상위 N개 제한을 적용하기 전에 전체 필터 대상에서 계산한다.

## 결측 처리

- 5개 미만 관측: 현재 강도, 구성요소, 강도 순위를 `null`로 반환한다.
- 충격일 없음: 신선도는 0점이며 경과일은 `null`이다.
- 30일 누적값 없음: 30일 순위에서 후순위로 배치한다.
- 같은 값은 동일한 평균 순위를 사용하며, 그다음 테마명으로 정렬 결과를 안정화한다.
