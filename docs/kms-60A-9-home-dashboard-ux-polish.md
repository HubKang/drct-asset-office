# 60-A-9 KMS 홈 UX/UI 대시보드화 개선

## 작업 목적
KMS 홈 화면을 요약 카드와 긴 보조 패널 중심의 화면에서, 사용자가 지식 현황과 다음 행동을 빠르게 파악할 수 있는 compact dashboard 형태로 개선했다.

## 기존 KMS 홈 문제점
- 태그 검색 영역과 카테고리 현황이 화면을 많이 차지했다.
- 카테고리별 0 값이 반복되어 정보 밀도가 낮아 보였다.
- 복습 필요, 실전 적용 후보, 최근 수정 흐름이 한 화면에서 명확히 구분되지 않았다.
- 홈에서 바로 이동할 수 있는 빠른 필터 동선이 부족했다.

## Hero 개선
- `DrCT KMS`를 첫 화면의 중심 타이틀로 유지했다.
- 설명 문구를 지식 대시보드 목적에 맞게 압축했다.
- 우측 액션을 `새 지식글 등록`, `지식 게시판` 두 버튼으로 정리했다.

## KPI 카드 개선
- 전체 지식글, 복습 필요, 실전 적용 후보, 핵심 지식, 최근 7일 KPI를 5개 카드로 유지했다.
- 카드 높이와 설명을 줄여 한눈에 스캔되도록 조정했다.
- 0 값은 muted tone으로 표시해 과도한 강조를 줄였다.
- 카드 클릭 시 지식 게시판의 해당 필터로 이동하도록 연결했다.

## 태그 검색 compact화
- 태그 입력, AND/OR, 검색 버튼을 한 줄로 정리했다.
- 인기 태그는 최대 10개만 노출한다.
- 선택 태그 영역은 선택된 태그가 있을 때만 표시한다.
- 검색 결과는 홈에서 최대 5건 미리보기로 표시한다.

## 빠른 필터 추가
- 복습 필요, 실전 적용 후보, 핵심 지식, 최근 7일, 전체 보기 버튼을 추가했다.
- 기존 게시판 URL 파라미터와 연결해 빠르게 목록으로 이동할 수 있게 했다.

## 대분류 카테고리 카드 compact화
- 기존 박스형 수치 나열 대신 inline metric으로 핵심/복습/후보/최근 지표를 표시했다.
- 0글 카테고리는 간단한 빈 상태 문구로 처리했다.
- 대표 태그와 마지막 수정일을 muted 정보로 작게 배치했다.
- 카테고리 클릭 시 해당 카테고리 게시판으로 이동한다.

## 하단 학습 흐름 섹션 개선
- 최근 작성/수정, 복습 필요, 실전 적용 후보를 3개 flow card로 분리했다.
- 각 카드에는 최대 5건만 표시한다.
- 빈 상태는 compact message로 표시한다.

## Backend/DB 변경 여부
- Backend 변경 없음.
- DB 스키마 및 데이터 변경 없음.

## 기존 기능 영향 여부
- KMS 홈의 표시 구조와 이동 동선만 변경했다.
- 기존 게시글 작성, 수정, 삭제, 태그 검색 API는 유지했다.
- 게시판은 홈에서 전달하는 `keyword`, `learning_status`, `importance` 초기 URL 파라미터를 읽도록 보강했다.

## 남은 이슈
- `recent=7` 파라미터는 현재 게시판의 실제 필터 조건으로는 처리하지 않는다. 홈 카드와 빠른 필터의 이동 힌트로만 남겨두었다.
- 태그 검색 전체 결과 이동은 게시판의 일반 키워드 검색으로 연결한다. 게시판 전용 태그 검색 결과 화면은 별도 작업으로 분리하는 것이 적절하다.
