# 한미테마비교 Phase 3-B — 테마별 선행 분석

## 목적

연결된 미국 테마의 거래일별 지표와 그 이후 첫 국내 실제 거래일의 테마등락률을 짝지어, 미국 D-1에서 국내 D0로 이어지는 방향성과 반응 강도를 검증한다.

## 거래일 매칭

- 미국 날짜보다 **엄격히 뒤인** 첫 국내 실거래일을 찾는다.
- 주말과 휴장은 건너뛰며, 달력상 간격이 7일을 초과하면 제외한다.
- 최근 60·120·250개의 유효 쌍 또는 전체 유효 쌍을 분석한다.
- 동일 날짜를 기계적으로 결합하지 않는다.

## 지표

- 미국 입력은 `theme_strength` 또는 `simple_return` 중 선택한다.
- 국내 반응은 `market_theme_daily_returns.avg_change_rate`를 사용한다.
- 방향 일치율 계산에서는 어느 한쪽이라도 0인 쌍을 제외한다.
- 미국 상승→국내 상승, 미국 하락→국내 하락 반응률을 별도로 계산한다.
- 국내 평균·중앙값, Pearson·Spearman 상관, 단순회귀선 기울기와 절편을 제공한다.
- 미국 상승 임계값은 `> 0`, `>= 1`, `>= 2`, `>= 3`, 하락 임계값은 `< 0`, `<= -1`, `<= -2`, `<= -3`이다.

## API

`GET /us-kr-theme-links/{link_id}/lead-analysis`

쿼리:

- `window`: `60`, `120`, `250`, `0`(전체)
- `us_metric`: `theme_strength`, `simple_return`

응답에는 연결 정보, 표본·제외 건수, 요약 통계, 임계값별 반응과 실제 거래일 쌍을 명시적인 필드로 반환한다.

## 데이터 보존

분석은 요청 시 원천 테이블을 일괄 조회하여 메모리에서 수행한다. 거래일 쌍, 산점도 계열, 임계값 계산 결과 및 API 원문은 별도 테이블이나 JSON 필드에 저장하지 않는다.
