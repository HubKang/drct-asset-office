# 미국 테마등락추이 UI/UX 통합

## 범위

`시장 테마 관리 > 미국 US > 테마등락추이`를 국내 KRX 화면과 같은 정보 계층으로 정리했다. 기존 미국 가격 수집, 테마 등락률 및 테마강도 계산식은 변경하지 않았으며 화면 조회를 위해 원천 데이터를 다시 수집하지 않는다.

## 조회 어댑터

- `GET /us-market-themes/returns/trend`는 `period=20|30|60`, 선택적 `end_date`, 선택적 `active` 조건을 받는다.
- 기준일은 저장된 미국 거래일 중 요청 기준일 이하의 최신 거래일이다.
- 응답에는 화면 필터, 상승 확산 요약 및 검증된 KRX 누적선에 필요한 명시적 필드만 포함한다: `theme_group_id`, `active`, `valid_stock_count`, `up_count`, `rolling_30d_simple_return`, `rolling_30d_theme_strength`, `rolling_30d_valid_count`.
- 제공사 원문 응답, 차트 원시 시계열, 검증 샘플은 추가 저장하지 않는다.

## 히트맵

- 기본 기간은 30거래일이며 20/30/60거래일을 선택할 수 있다.
- 날짜 헤더는 `DD`로 표시하고 첫 열과 월 경계에서 `M월` 표식을 표시한다. 전체 날짜는 `title`과 접근성 레이블로 유지한다.
- 미국 시장은 실제 저장 거래일만 사용하므로 국내 KRX의 `D+1` 예상 열을 표시하지 않는다.
- 데스크톱의 20/30거래일은 고정 레이아웃으로 가로 스크롤 없이 맞추고, 60거래일과 좁은 화면에서는 가로 스크롤을 허용한다.
- 결측값은 `-`로 표시하며 임의 보간하지 않는다.

## 통합 선그래프

- 테마별 개별 스파크라인을 하나의 SVG 좌표계와 공통 Y축을 사용하는 통합 선그래프로 교체했다.
- 국내 KRX와 동일하게 각 관측일을 기준으로 최근 30일 동안의 일별 테마 값을 단순 합산한 값을 선의 Y축 값으로 사용한다. 히트맵은 일별값을 유지한다.
- 범례 hover/focus 시 해당 테마를 강조하고 다른 선은 약화한다.
- 각 거래일 포인트의 툴팁은 테마명, 전체 날짜, 30일 누적값을 제공한다.
- 결측 구간은 선을 연결하지 않는다. 범례에는 30일 누적값과 최근 일별값을 표시한다.
- 범례 또는 포인트 선택 시 기존 일별 상세 패널을 연다.

## 공통 도구 모음과 요약

- Desktop에서는 기준일, 기간, 테마그룹, 활성 상태, 테마명/키워드, 새로고침, 계산 기준을 한 줄 Toolbar에 배치한다.
- 검증된 화면 계층에 맞춰 히트맵/선그래프 선택은 4개 요약 카드 오른쪽의 고정 패널에 배치한다.
- 테마강도/단순등락률과 히트맵/선그래프 전환은 이미 조회한 데이터를 재사용한다.
- 현재 강도, 30일 누적, 상승 확산, 상승 지속 1위를 같은 기준일 데이터로 계산해 표시한다.
- 30일 누적 Summary는 1~2일 데이터가 순위를 왜곡하지 않도록 최근 30일 유효 관측이 20일 이상인 테마만 후보로 사용한다. 저장된 계산값은 변경하지 않는다.

## 최신 거래일 정렬

- 그룹과 검색 필터를 먼저 적용한 뒤, 조회 결과의 실제 최신 거래일에서 선택 지표가 높은 순서로 Frontend 메모리 정렬한다.
- 최신값 결측은 `0`으로 바꾸지 않고 값이 있는 테마 아래에 둔다.
- 동률은 최신 30일 누적값 내림차순, 테마명 오름차순, 기존 배열 위치 순으로 고정한다.
- 동일하게 정렬한 배열을 히트맵 행과 선그래프 범례에 전달한다.
- 선그래프 색상은 배열 위치가 아니라 `theme_id`로 정해 정렬이 바뀌어도 유지한다.
- 국내 KRX 정렬 정책에는 이 규칙을 적용하지 않는다.

## 회귀 원칙

- 국내 KRX 화면과 계산 로직은 수정하지 않는다.
- 미국 테마 상세 패널, 종목 연결, 가격 수집 및 테마 갱신 흐름은 유지한다.
- 반응형 구간에서는 도구 모음과 요약 카드를 단일 열까지 단계적으로 축소한다.
