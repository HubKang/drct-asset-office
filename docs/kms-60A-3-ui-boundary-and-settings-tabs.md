# 60-A-3 DrCT KMS UI 식별성 강화 및 설정 탭 구조 개선

## 작업 목적

DrCT KMS 화면의 패널, 카드, 목록 경계를 강화해 정보 영역을 명확히 구분하고, KMS 설정 화면을 향후 확장 가능한 탭 구조로 정리했다. 또한 `/kms` 링크의 기본 prefix active 동작으로 인해 KMS 홈이 다른 KMS 하위 화면에서도 하이라이트되는 문제를 수정했다.

## 현재 문제점

- KMS 홈의 태그 통합 검색, 대분류 카테고리 영역 경계가 약했다.
- 지식 게시판에서 등록 폼과 검색/필터/목록 영역이 한 화면에서 섞여 보였다.
- KMS 설정의 카테고리 목록이 카드처럼 구분되지 않고, 향후 기능 확장을 위한 탭 구조가 없었다.
- `/kms/settings` 등 하위 경로에서도 KMS 홈 active 표시가 남았다.

## Active Menu 수정 기준

- `/kms`, `/kms/`: KMS 홈만 active
- `/kms/posts`, `/kms/posts/:postId`: 지식 게시판만 active
- `/kms/settings`: KMS 설정만 active
- KMS 외 다른 경로에서는 KMS 하위 메뉴 active 표시 없음

## KMS 홈 개선

- 요약 카드를 `kms-summary-card`로 정리하고 경계, 높이, 설명을 강화했다.
- 태그 통합 검색은 입력 영역, 인기 태그, 선택 태그, 검색 결과를 별도 패널로 분리했다.
- 대분류 카테고리 카드는 metric grid, 대표 태그, 마지막 수정일을 카드 안에서 명확히 표시하도록 정리했다.

## 지식 게시판 개선

- 기본 화면은 목록/검색 중심으로 유지하고, 새 지식 등록은 버튼 클릭 시 펼침 패널로 표시한다.
- 검색/필터 패널 안에서 카테고리 사이드바와 게시글 목록 패널을 분리했다.
- 빈 상태 카드는 안내 문구와 새 지식 등록 버튼을 제공한다.

## KMS 설정 탭 구조

설정 화면 상단에 다음 탭을 추가했다.

- 카테고리
- 태그관리
- 템플릿
- 관계설정

현재는 카테고리 탭만 실제 기능을 제공하며, 나머지는 준비 중 안내 카드로 표시한다.

## 카테고리 목록/수정 폼 개선

- 카테고리 목록은 compact list item으로 정리하고 선택 항목은 accent bar와 배경색으로 강조한다.
- 활성/비활성 상태는 작은 pill badge로 표시한다.
- 수정 폼은 독립 패널로 분리하고, 필드 경계와 버튼 위계를 강화했다.

## Backend/DB 변경 여부

이번 작업에서는 backend와 DB를 변경하지 않았다.

## 남은 이슈

- 태그관리, 템플릿, 관계설정 탭은 다음 단계에서 실제 기능 연결이 필요하다.
- 카테고리별 글 수 badge를 사이드바에 표시하려면 요약 API 또는 게시글 집계 데이터 연동이 필요하다.
