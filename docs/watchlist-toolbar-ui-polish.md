# 관심종목 버튼 toolbar UX 정리

## 작업 목적
관심종목 화면 상단 기능 버튼이 여러 줄로 흩어지고 긴 수집 설명이 본문에 노출되어 화면 집중도가 떨어지는 문제를 정리했다.

## 기존 문제점
- 뉴스 수집, 공시 수집, 최근7일수집, 전체수집, GPT 자료 패키지, Data분석 이동 버튼이 한 흐름 안에서 구분 없이 배치되었다.
- 수집 설명 문구가 화면 본문에 길게 노출되었다.
- 관심종목 운영 목록 제목이 카드 제목과 내부 제목으로 중복 표시되었다.

## 버튼 그룹 재배치
버튼을 정보 수집, 가격/데이터 수집, GPT 활용 그룹으로 분리했다.

- 정보 수집: 뉴스수집, 공시수집
- 가격/데이터 수집: 최근7일수집, 전체수집, 수집 기준 도움말
- GPT 활용: GPT자료패키지

그룹 사이에는 세로 구분선을 두고, 좁은 화면에서는 그룹 단위로 줄바꿈되도록 했다.

## Data분석 이동 버튼 제거
관심종목 화면의 Data분석 이동 버튼 UI만 제거했다. 라우트, API, 다른 화면의 기능은 삭제하지 않았다.

## 수집 설명 도움말 전환
기존 본문 설명 문구를 전체수집 옆 ? 도움말 버튼으로 이동했다. 도움말은 클릭 시 열리고, 바깥 클릭 또는 ESC 입력 시 닫힌다.

## 기존 기능 영향 여부
뉴스수집, 공시수집, 최근7일수집, 전체수집 확인 모달, GPT자료패키지 이동 로직은 기존 API 호출과 동일하게 유지했다.
