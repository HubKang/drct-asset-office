## 8월 2일 테마등락률

2026-08-02는 일요일이다. DB의 가격·투자자 수급·프로그램 수급·테마등락률 최신 거래일은 2026-07-31이며 8월 2일 행이 없는 것이 정상이다. 통합 작업은 주말에는 당일 테마등락률 외부 조회와 저장을 실행하지 않고 최근 거래일을 기준일로 반환한다. 기존 7월 31일 데이터는 유지한다.

기존 화면의 `테마등락률 34/34`는 34개 테마에서 실제 등락률을 저장했다는 뜻이 아니라 34개 테마 처리가 오류 없이 끝났다는 집계였다. 이제 주말 결과는 `성공 0 · 생략 34 · 실패 0`으로 구분한다.

## 수집 경로

- 가격: `StockPriceService.refresh_theme_stock_price_ranges` → Kiwoom REST 공통 가격 provider → `stock_daily_prices`
- 기술지표: 가격 insert/update 종목만 기존 `TechnicalIndicatorService` 실행
- 투자자: 기존 `StockInvestorFlowService`와 ka10059 파서 재사용
- 프로그램: 기존 ka90013 파서 재사용
- 저장: 투자자와 프로그램 모두 `(stock_id, flow_date)` 공통 `stock_investor_flows` 행에 부분 upsert

신규 종목은 달력 6개월, 기존 종목은 7일 overlap 정책을 사용한다. 주말 기준 최근 금요일까지 가격과 해당 수급 주체가 존재하면 외부 호출 없이 `UP_TO_DATE`로 처리한다.

## 상태 정의

- `SUCCESS`: 외부 조회·파싱·저장이 정상 완료됨
- `UP_TO_DATE`: 최근 예상 거래일까지 DB에 있어 호출 불필요
- `NO_DATA`: 정상 요청이었지만 조회 구간에 실제 데이터가 없음
- `SKIPPED`: 가격 미변경 등 정책상 후속 단계 미실행
- `FAILED`: 인증·네트워크·파싱·저장·계산 오류

각 단계는 대상, 호출, 성공, 최신, 데이터 없음, 생략, 실패, insert, update를 반환한다. 실제 실패가 없으면 insert가 0이어도 `COMPLETED`다. 가격·투자자·프로그램이 대상 전체에서 공통 실패하면 테마 처리 성공 여부와 무관하게 `FAILED`다.

## 실패 상세

실패 응답에는 단계, 종목, 오류 코드, 사용자 메시지, 내부 요약, 재실행 가능 여부를 반환한다. 화면의 `실패 상세` 영역은 같은 오류 코드를 묶어 종목 수와 대표 메시지를 표시하며 stack trace나 인증정보는 노출하지 않는다.
