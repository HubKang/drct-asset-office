# 대시보드 주요 지표 네이버 차트 패널

## 작업 개요

DrCT 대시보드의 `최근 1개월 테마등락률 트리맵` 상단에 `주요 지표 흐름` 패널을 추가했다. 국내지수, 해외증시, 환율, 원자재 흐름을 네이버 차트 이미지 기준으로 빠르게 확인할 수 있도록 구성했다.

## 표시 지표

- 코스피: 네이버 국내지수 90일 차트
- 코스닥: 네이버 국내지수 90일 차트
- 국제 금: 네이버 시장지표 3개월 차트
- 다우지수: 네이버 해외증시 3개월 차트
- 나스닥: 네이버 해외증시 3개월 차트
- S&P500: 네이버 해외증시 3개월 차트
- 달러 환율: 네이버 시장지표 3개월 차트
- 달러 인덱스: 네이버 시장지표 3개월 차트
- WTI: 네이버 시장지표 3개월 차트

## 구현 방식

- `frontend/src/utils/naverChart.ts`의 공통 네이버 차트 URL helper를 사용한다.
- `createNaverChartSidcode()`를 `DashboardPage` mount 시점에 한 번 생성해 이미지 캐시 갱신값으로 사용한다.
- 차트 이미지는 `loading="lazy"`로 로드한다.
- 달러 인덱스 카드의 `?` 버튼은 설명 모달을 열며, 배경 클릭 또는 `닫기` 버튼, `Escape` 키로 닫을 수 있다.

## 영향 범위

- backend, DB, 수집 로직, 테마등락률 트리맵 데이터 로직은 변경하지 않았다.
- 기존 트리맵 섹션은 새 패널 아래로 위치만 밀리며, 조회 및 표시 로직은 유지된다.
- `TradeTrainingPage.tsx`는 변경하지 않았다.
