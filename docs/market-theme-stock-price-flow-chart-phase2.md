# 시장테마 연결 종목 가격·수급 통합 차트 — 2단계

## 목적과 화면 위치

시장 테마 관리의 `종목 연결` 목록에서 종목을 선택하면 상세 Drawer에 저장된 가격과 투자주체별 수급을 한 차트로 비교한다. 신규 영역은 기존 외국인·기관 매매동향 이미지 아래, 기존 수급 이력 위에 배치한다. 기존 이미지 확대, 수급 이력, 종목 메모, 연결 해제 기능은 유지한다.

## 데이터 재사용과 보존 정책

- 가격: `stock_daily_prices`
- 개인·외국인·기관·프로그램 수급: `stock_investor_flows`
- 수급 이벤트·종목 메모: `market_trend_events`, `market_trend_event_theme_links`
- 차트 진입과 옵션 전환은 저장 데이터만 읽으며 Kiwoom API 또는 수집 작업을 호출하지 않는다.
- 누적값, 정규화값, 차트 좌표, 요약 카드는 응답 시점에 계산한다.
- 신규 테이블과 영구 JSON 필드를 만들지 않는다.

## 기간과 기준일

달력 개월이 아닌 실제 저장 거래일 개수를 사용한다.

- 1M: 20거래일
- 3M: 63거래일
- 6M: 126거래일

가격, 투자자 수급, 프로그램 수급의 최신일을 각각 구하고 모두 비교할 수 있는 가장 늦은 공통일을 `common`으로 사용한다. 요청 기간보다 데이터가 짧으면 보유한 거래일만 반환하고 `PERIOD_SHORT` 또는 누락 우선순위에 따라 `PARTIAL` 상태를 표시한다.

## 누적 수급과 가격 계산

기간을 바꿀 때 첫 거래일부터 각 주체를 독립적으로 다시 누적한다.

```text
cumulative_subject(t) = sum(daily_net_subject from period start through t)
price_return_pct(t) = (close(t) / first_valid_close - 1) * 100
```

수량은 `*_net_qty`, 금액은 `*_net_amount`를 사용한다. 프로그램 수급은 별도의 매매 방식 보조지표이며 개인·외국인·기관 합계에 포함하거나 차감하지 않는다. 특정 날짜 값이 없으면 해당 날짜의 선 값은 `null`로 끊되 내부 누적값은 직전 유효값을 유지해 다음 유효일에 누적을 계속한다. 실제 0과 결측 `null`은 구분한다.

## 실제 누적과 패턴 비교

`실제 누적`은 왼쪽 축에 주가 기간 수익률, 오른쪽 축에 주체별 누적 순매수를 표시한다. `패턴 비교`는 각 선을 기간 내 최대 절댓값으로 독립 정규화한다.

```text
normalized(t) = value(t) / max(abs(value over selected period)) * 100
```

최대 절댓값이 0이면 유효한 값은 0으로 반환한다. 결측은 그대로 `null`이며 NaN과 Infinity는 응답하지 않는다. 정규화 선은 실제 규모 비교가 아니라 방향과 전환 시점 비교 용도다.

## 수급 이벤트 마커

기존 수급 이력과 종목 메모 데이터를 선택 기간에 한 번 조회한다. 같은 날짜의 여러 이벤트는 하나의 마커와 건수로 묶는다. 현재 조회 중인 테마 연결은 강조하고, 마커 또는 차트를 선택하면 아래 상세 카드에 테마명과 메모를 표시한다.

## 조회 API

```http
GET /external/kiwoom/market-themes/stocks/{stock_id}/price-flow-chart
    ?period=1M|3M|6M
    &unit=QUANTITY|AMOUNT
    &view=ACTUAL|NORMALIZED
    &theme_id={current_theme_id}
```

응답은 종목, 요청 옵션, 기간, 최신일, 데이터 품질, 요약, 일별 series, 날짜별 events를 명시적 필드로 반환한다. 잘못된 옵션은 400, 없는 종목은 404다. 데이터가 없는 등록 종목은 200과 `EMPTY`를 반환한다.

## UI와 상태 처리

- 기본값: 3M / 실제 누적 / 수량
- 요약: 기간 수익률과 개인·외국인·기관·프로그램 누적, 순매수일, 최신 연속 방향
- 범례: 각 선 표시·숨김
- hover와 클릭: 같은 날짜의 종가, 일간 등락률, 기간 수익률, 일별·누적 수급 표시
- 프로그램: 보라색 점선으로 일반 투자주체와 시각적으로 구분
- 품질 상태: 충분, 기간 부족, 일부 누락, 최신일 불일치, 데이터 없음
- Drawer 내부 스크롤과 기존 닫기 동작 유지

## 검증 결과

- 신규 백엔드 계산·라우트 테스트: 9개 통과
- 1M 20일, 3M 63일, 6M 보유일 반환 검증
- 수량·금액 누적, 기간 시작 재설정, 결측 구간 누적 지속 검증
- 각 선 독립 정규화와 0 분모 처리 검증
- 동일 날짜 이벤트 묶음과 현재 테마 강조 검증
- 두산로보틱스 3M: 63거래일, `ENOUGH`
- SK하이닉스 실제 Drawer: 3M 63/63일, 이벤트 마커와 현재 테마 메모 표시 검증
- 브라우저에서 1M·금액·패턴 비교 전환과 정규화 안내 확인
- 프런트 프로덕션 빌드 통과
- 조회 전후 가격·수급 행 수와 SQLite 테이블 수 불변 확인
