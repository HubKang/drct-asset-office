# 60-A-10 KMS 홈 시각 위계 및 카테고리 카드 식별성 개선

## 작업 목적
KMS 홈 화면에서 과도하게 굵은 텍스트를 줄이고, 대분류 카테고리 카드의 개별 식별성을 강화해 핵심 정보와 보조 정보가 더 쉽게 구분되도록 개선했다.

## 현재 문제점
- KMS 홈 전반에서 `font-weight`가 강하게 적용되어 시선이 분산되었다.
- KPI 라벨, 설명, 태그, 보조 문구까지 비슷한 강도로 보여 정보 위계가 약했다.
- 대분류 카테고리 카드의 경계가 약해 개별 카드 구분이 명확하지 않았다.
- 0글 카테고리와 1글 이상 카테고리의 정보 강도 차이가 작았다.

## Bold Text 축소 기준
- 페이지 제목과 섹션 제목, KPI 숫자, 카테고리명은 강조를 유지했다.
- 설명, 보조 문구, empty state, 마지막 수정일은 normal/muted tone으로 낮췄다.
- chip, quick filter, badge 계열 텍스트는 500 전후로 낮춰 과한 강조를 줄였다.

## KPI 카드 시각 위계 보정
- KPI 라벨은 600, 숫자는 700, 설명은 400으로 조정했다.
- 0 값은 기존 위치와 크기를 유지하면서 muted color로 표시했다.
- 카드 경계는 subtle하게 유지해 다른 콘텐츠보다 과하게 튀지 않게 했다.

## 태그 검색 영역 위계 보정
- 섹션 제목만 강조하고 설명은 normal weight로 낮췄다.
- 인기 태그와 선택 태그 chip의 font weight를 낮췄다.
- 빠른 필터 버튼은 pill 형태를 유지하되 텍스트 강도를 낮췄다.

## 대분류 카테고리 카드 경계 강화
- 카테고리 카드를 명확한 개별 카드로 보이도록 border, radius, subtle shadow를 조정했다.
- 카드 간 gap을 늘려 각 카테고리의 구분감을 높였다.
- hover 시 border와 shadow가 약하게 강화되도록 했다.

## 0글/1글 이상 상태 표시 기준
- 0글 카테고리는 불필요한 핵심/복습/후보/최근 0 반복을 숨기고 empty 문구만 표시한다.
- 1글 이상 카테고리는 핵심/복습/후보/최근 지표를 가벼운 inline metric으로 표시한다.
- 대표 태그 없음, 마지막 수정 없음 문구는 muted tone과 normal weight를 적용했다.

## 하단 학습 흐름 섹션 보정
- 섹션 제목은 강조를 유지했다.
- 게시글 제목은 600으로 낮췄고, 카테고리/수정일 정보는 muted normal text로 낮췄다.
- 빈 상태 문구도 normal weight로 조정했다.

## Backend/DB 변경 여부
- Backend 변경 없음.
- DB 변경 없음.

## 기존 기능 영향 여부
- 기능 동작 변경 없음.
- 홈 화면의 CSS 시각 위계와 카테고리 카드 마크업 클래스만 조정했다.

## 남은 이슈
- 실제 브라우저에서 데이터가 많은 상태와 0글 상태를 각각 육안 확인하는 것이 좋다.
