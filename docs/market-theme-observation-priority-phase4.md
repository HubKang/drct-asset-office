# Phase4 테마관찰우선순위

## 목적과 표시 계약

Phase4의 운영 목적은 D+1 수익률 숫자 예측이 아니라, 대상일 유니버스 안에서 실제 수익률 Top20%에 들 테마를 먼저 관찰하도록 순위를 제공하는 것이다. 화면의 `D+1` 표시는 유지하지만 값은 다음 둘 중 하나만 허용한다.

- `PROBABILITY`: 시간순 내부 보정 및 Calibration Gate를 통과한 Top20 상대강도 확률(0~100%)
- `SCORE`: 설명 가능한 관찰 RULE 점수(0~100점). 확률이 아님을 화면과 툴팁에 명시한다.

기존 `THEME_RETURN_FEATURE_V1/V2`, Phase1~3 모델과 공식 RULE 실행은 변경하지 않는다. Phase4는 `THEME_OBSERVATION_FEATURE_V1`과 `market_theme_observation_*` 테이블을 사용한다.

## 데이터 감사 및 시점 정책

2026-08-08 실제 SQLite 감사 기준으로 테마 일별 2,483건/530일, 테마-종목 일별 6,668건/530일, 종목 가격·기술지표 각 22,382건/536일, 투자자 수급 19,211건/126일, 시장지수 10,921건을 확인했다. 뉴스는 121건/12개 수집일, 종목 시장지표는 26건/9일이라 시간축 학습에서 제외했다. 경제 텍스트·시나리오도 과거 가용 시점의 정량 재현성이 부족해 제외했다.

미국 지수·금리·달러·WTI는 한국 기준일보다 엄격히 이전 날짜의 값만 사용한다. 국내 KOSPI/KOSDAQ과 KRX 금은 기준일 값까지 사용한다. 누락은 `None`으로 유지하고 0으로 바꾸지 않는다.

## 유니버스와 검증

- 최소 평가 테마 10개이면서 활성 leaf 테마의 50% 이상
- 정답은 대상일 유니버스 내부 수익률 순위와 Top20% 여부
- 날짜 그룹 기준 expanding walk-forward 4 folds
- 각 outer fold 학습 구간의 마지막 20% 날짜만 Platt 보정에 사용
- 모델 학습/전처리는 그보다 앞선 날짜에만 fit
- 기준선: 현재일 순위, 3일 모멘텀, 관찰 RULE
- Gate: 최고 기준선 대비 Top20 정밀도 +3%p, NDCG@5 이상, 절반 이상 fold 개선, 보정 ECE ≤ 0.15 및 보정 Brier가 raw보다 0.01 이상 악화되지 않음

## 실제 학습 결과

적격 학습 기준일 28개, 859행, 4 folds였다. LOGISTIC과 HGBC 모두 보정 Gate는 통과했지만 운영 승격 Gate는 실패했다. 관찰 RULE Top20 정밀도 0.2449/NDCG@5 0.2035에 비해 LOGISTIC은 0.2245/0.1956, HGBC는 0.2245/0.2026이었다. 따라서 운영 화면은 `OBSERVATION_RULE / SCORE` 모드를 유지한다. 2026-08-10 관찰 실행은 35개 테마를 저장했으며 1위는 2차전지(86.7점)다.

상세 피처 행렬, fold별 샘플, 보정 bin은 저장하지 않고 모델 레지스트리의 집계 지표만 보존한다.
