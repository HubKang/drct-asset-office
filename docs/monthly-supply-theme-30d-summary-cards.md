# 월별 수급 테마 최근 30일 요약 카드

## 화면 구성

시장 수급 테마(종목)의 월별 수급 테마(종목) 탭은 월 이동 컨트롤 오른쪽에 다음 5개 요약 카드를 표시한다.

1. 등장 테마 수
2. TOP 테마
3. TOP1 종목
4. TOP2 종목
5. TOP3 종목

월간 달력은 사용자가 선택한 월을 표시하지만, 요약 카드는 선택 월과 독립적으로 항상 한국시간 오늘 기준 최근 30일을 사용한다. 시작일은 오늘에서 30일을 뺀 날짜이며 시작일과 종료일을 모두 포함한다. 화면의 기간 배지는 백엔드 응답의 `period_start_date`와 `period_end_date`를 그대로 사용한다.

## 집계 기준

- 활성 상태이며 삭제되지 않은 저장 수급 이벤트 후보만 포함한다.
- 등장 테마 수는 기간에 한 번 이상 등장한 고유 활성 테마 수다. 테마가 연결되지 않은 종목은 제외한다.
- TOP 테마 출현 횟수는 동일 날짜·동일 테마를 1회로 계산한다. 같은 날 여러 연결 종목이 감지되어도 중복 증가하지 않는다.
- TOP 종목 출현 횟수는 동일 날짜·동일 종목을 1회로 계산한다. 같은 날 여러 조건이나 여러 테마로 저장되어도 중복 증가하지 않는다.
- 테마가 연결되지 않은 종목도 TOP 종목 순위에는 포함한다.

## 동률 정렬

TOP 테마는 출현일 수, 최근 출현일, 기간 내 고유 감지 종목 수의 내림차순과 테마명 오름차순으로 결정한다.

TOP 종목은 출현일 수, 최근 감지일, 기간 내 일별 평균 등락률의 내림차순과 종목명 오름차순으로 결정한다.

## API

`GET /external/kiwoom/theme-flow/monthly/calendar?month=YYYY-MM`

기존 월별 달력 응답을 유지하면서 `summary_30d`를 추가한다.

```json
{
  "summary_30d": {
    "period_start_date": "2026-06-22",
    "period_end_date": "2026-07-22",
    "appeared_theme_count": 20,
    "top_theme": {
      "theme_id": 10,
      "theme_name": "전력인프라",
      "appearance_count": 12,
      "latest_appearance_date": "2026-07-22",
      "unique_stock_count": 26
    },
    "top_stocks": []
  }
}
```

TOP 종목이 3개 미만이면 응답에는 존재하는 항목만 포함하고, 화면은 누락 순위를 `-`로 표시한다.
