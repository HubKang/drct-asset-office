# 월별 수급 TOP20 종목 누적등락률 선그래프

## 화면

`시장 수급 테마(종목) > 월별 수급 테마(종목)`의 최근 1개월 히트맵·트리맵 아래에 최근 30일 수급 TOP20 종목 누적등락률을 표시한다. 기존 히트맵과 트리맵은 그대로 유지한다.

오른쪽 범례는 수급 순위를 유지하며 종목명, 고유 수급일 수, 최신 누적등락률을 보여준다. 선 또는 범례에 마우스를 올리면 같은 종목을 강조한다. 가격이 2개 미만인 종목은 순위에서 제거하지 않고 `데이터 부족`으로 표시한다.

## 집계 기준

- 기간: 월간 캘린더 API가 반환한 한국시간 기준 최근 30일 `period_start_date` ~ `period_end_date`
- 순위: `(stock_id, detected_date)` 고유 수급일 수 내림차순, 최근 수급일 내림차순, 종목명 오름차순
- 기준 종가: 기간 시작일 이전의 가장 최근 거래일 종가. 없으면 기간 내 첫 종가
- 누적등락률: `(해당일 종가 / 기준 종가 - 1) * 100`
- 결측 거래일: `null`로 취급하여 선을 연결하지 않음

## API와 저장 정책

`GET /external/kiwoom/theme-flow/monthly/top-stock-return-trend`에 `period_start_date`, `period_end_date`, `limit`을 전달한다. 종목 순위 집계 후 선택된 종목의 `stock_daily_prices`를 한 번의 배치 쿼리로 읽는다. 외부 시세 API를 호출하지 않으며 종목별 N+1 조회를 하지 않는다.

그래프 시계열은 기존 수급 이벤트와 일별 종가에서 조회 시 계산한다. 별도 JSON, 차트 시계열, 시뮬레이션 원천 데이터를 DB에 저장하지 않는다.
