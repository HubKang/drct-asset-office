# DrCT 종목 시그널 Phase 6-C.2 — Marker Pattern 판별력 검증

## 1. 목적과 범위

Phase 6-C.2는 성공(S) 사례의 LOO 유사도 분포와 현재 분석 Universe의 유사도 분포를 동일한 0~100 척도에서 비교하는 진단 단계다. 현재 Universe는 Negative Dataset이 아니며, 분포 차이와 후보 폭은 성공률이나 정확도로 해석하지 않는다.

운영 후보 기준은 기존 Marker별 S-only LOO P25를 유지한다. Median, P75, P90은 연구용 시뮬레이션이며 Scan 결과, DB, 알고리즘 버전에는 반영하지 않는다.

## 2. 계산 구조

- 기존 Current Pattern Scan에서 이미 계산한 Marker × 현재 종목 유사도를 메모리에서 재사용한다.
- S LOO 분포는 기존 Signature V1의 percentile 정의와 동일한 선형 보간을 사용한다.
- Marker별로 `min`, `p10`, `p25`, `median`, `p75`, `p90`, `max`, `n`을 계산한다.
- 각 임계값에서 Pair 수, 중복 제거 종목 수, 복수 Marker 종목 수를 계산한다.
- 응답은 집계값과 화면 검토용 소량 샘플만 명시 필드로 제공하며 원시 벡터는 제공하지 않는다.
- 진단 계산으로 추가되는 SQL은 0건이며, 결과는 Runtime에서만 존재한다.

## 4. 전체 Threshold 정책 비교

| 연구 기준 | Candidate Pair | Candidate Stock | 복수 Marker 종목 |
|---|---:|---:|---:|
| 현재 P25 | 224 | 142 | 71 |
| Median | 161 | 122 | 39 |
| P75 | 20 | 16 | 4 |
| P90 | 15 | 14 | 1 |

P25에서 가장 넓은 Marker는 `전저점 / 전Box상단` 141건(75.4%), 가장 좁은 Marker는 `전고점 / 매물대` 7건(3.7%)이다. P75/P90에서는 10건(5.3%)을 넘는 Marker가 없어 고임계값에서도 후보가 과도하게 넓은 사례는 확인되지 않았다. Marker별 결과 차이가 커 Marker별 Threshold 정책 또는 Shape Feature 연구 가치는 있으나, 이번 단계에서는 어느 방향도 선택하거나 구현하지 않는다.

## 5. UX

- 메인 종목 시그널 화면에는 보조 액션 `[판별력 검증]`만 추가했다.
- Drawer는 기본 닫힘이며 기존 후보 2열 Card와 필터를 바꾸지 않는다.
- Marker Overview에서 S 학습 수와 P25/Median/P75/P90 후보 수를 비교한다.
- 성공 S LOO와 현재 Universe 분포는 동일 0~100 범위 막대로 표시한다.
- Threshold 전환은 Drawer 내부 표시만 바꾸며 운영 후보 142종목을 변경하지 않는다.
- 임계값별 상위 샘플과 P90/P75/Median/P25 경계구간을 기존 상세 차트로 연다.
- P25 미만 사례도 기존 상세 화면을 재사용하며 `현재 후보 아님`을 명시한다.

## 6. 데이터 및 버전 정책

- 신규 테이블 및 Migration 없음
- 진단 결과, Universe 분포, 시뮬레이션, 차트 검토 결과 저장 없음
- Search, F 사례, Outcome 미사용
- 원시 유사도 벡터 API 노출 없음
- Marker Pattern Signature V1, Similarity V1, CORE Feature Schema V1 유지

## 7. 검증 기준

- P25 운영 후보 224 Pair / 142종목 불변
- 추가 SQL 0건: 날짜 지정 Scan 총 3건, 최신 날짜 조회 포함 총 4건
- 실제 DB 연속 5회 Scan service time 중앙값 602ms (596~884ms, 실행 환경 부하에 따라 변동)
- 1920×1080, 1440×900, 900×900에서 문서 및 Drawer 수평 overflow 없음
- P25 미만 사례 상세 진입과 `현재 후보 아님` 표시 확인
- 브라우저 console error 0건

## 8. 해석 원칙과 다음 결정

현재 결과는 Threshold 및 Feature 연구의 근거이지 성공/실패 판정이 아니다. Shape Feature V1 진입은 P75/P90에서도 후보가 넓고 Universe와 S 분포가 지속해서 겹치는 경우에만 다음 Phase 후보로 검토한다. 운영 P25 유지, Median/P75 전환, Marker별 기준, Shape Feature 우선 중 무엇을 선택할지는 이 결과를 사용자와 검토한 뒤 결정한다.
