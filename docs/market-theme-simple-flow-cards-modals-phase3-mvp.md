# 시장테마 단순 수급 카드·모달 3단계 MVP

## 목적

테마 등락추이 상세 Drawer 안에서 당일 수급 방향을 빠르게 확인하고, 필요한 경우에만 종목 또는 테마의 가격·수급 차트를 모달로 열어 탐색한다. 이 단계는 저장된 가격·수급 데이터만 읽으며 외부 수집, 신규 테이블, 파생 차트 데이터 저장을 수행하지 않는다.

## 화면 구성

- 테마 상세 KPI 아래에 개인·외국인·기관·프로그램 4개 테마 수급 카드를 표시한다.
- 프로그램은 투자주체 합계와 섞지 않고 별도 보조 수급 카드와 점선 차트로 표시한다.
- 연결 종목 목록에는 등락률과 일봉 사이에 `개외기 수급` 요약 카드를 한 칸으로 표시한다.
- 종목 카드는 개·외·기의 방향, 요약 코드, 프로그램 방향을 표시한다. 마우스를 올리면 당일 실제 순매수 금액과 거래대금 대비 강도를 확인할 수 있다.
- 종목 카드를 클릭하면 기존 2단계 종목 가격·수급 차트를 기본 `3M / 실제 누적 / 수량`으로 연다.
- 테마 수급 카드를 클릭하면 기본 `3M / 금액 / 실제 누적` 테마 차트를 열고 선택한 투자주체를 우선 표시한다.
- 모달은 상세 Drawer보다 위에 표시되며 닫기 버튼, 배경 클릭, `Esc`로 닫는다. 모달을 닫아도 Drawer는 유지된다.

## 계산 기준

- 집계 대상: 조회 시점의 활성 테마-종목 연결 전체
- 귀속 방식: `FULL`
- 수급 강도: `투자주체 순매수 금액 / 종목 또는 테마 거래대금 × 100`
- 거래대금이 없거나 0이면 강도는 `null`이며, 결측 수급을 0으로 치환하지 않는다.
- 강도의 절댓값이 `0.1%` 미만이면 중립으로 표시한다.
- 종목 요약 코드는 `외국인·기관 동반`, `외국인 우위`, `기관 우위`, `개인 우위`, `외국인·기관 매도`, `혼조`, `수급 없음` 범위만 사용한다. 투자 권유 문구는 만들지 않는다.
- 테마 수익률은 일간 평균 등락률을 복리 누적한다.
- 투자주체별 테마 수급은 일간 금액을 누적하며 프로그램은 별도 계열로 유지한다.

## 완전성

- `ENOUGH`: 완전 데이터 종목 비율 90% 이상
- `PARTIAL`: 60% 이상 90% 미만
- `INSUFFICIENT`: 0% 초과 60% 미만
- `EMPTY`: 완전 데이터 종목 0개

화면과 API는 연결 종목 수, 투자자 데이터 종목 수, 프로그램 데이터 종목 수, 완전 데이터 종목 수를 함께 제공한다.

## API

`GET /external/kiwoom/market-themes/{theme_id}/price-flow-chart?period=3M&focus_date=YYYY-MM-DD`

- 기간: `1M` 20거래일, `3M` 63거래일, `6M` 126거래일
- 응답: 공통 최신일, 데이터 품질, 기간 요약, 테마 복리 수익률, 투자주체별 일간·누적 금액, 완전성, 선택 기준일
- 기존 최신/일별 테마 상세 응답에는 테마 `flow_summary`와 각 종목 `flow_summary`를 추가한다.
- 상세 수급은 한 번의 배치 쿼리로 계산하며 종목별 반복 조회를 하지 않는다.

## 검증 결과

- 1·2·3단계 관련 백엔드 테스트: 35개 통과
- 프런트엔드 TypeScript 및 프로덕션 빌드 통과
- 실데이터 파일 무결성: `ok`
- AI반도체/HBM(테마 ID 2, 13종목, 2026-07-31): 완전 데이터 12종목, 완전성 92.31%, `ENOUGH`
- 실데이터 계산 시간: 당일 요약 약 5ms, 3개월 차트 약 4ms(로컬 단일 실행 기준)
- 3개월 차트의 실제 보유 이력은 27거래일이며 기준일 선택이 정상 반영됨
- 검증 전후 테이블 및 가격·수급 원천 행 수는 변경하지 않는다.
