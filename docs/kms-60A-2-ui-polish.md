# 60-A-2 DrCT KMS UX/UI 보완

## 작업 목적

60-A에서 구현한 DrCT KMS MVP 화면의 정보 식별성과 조작성을 높이고, 좌측 메뉴에서 KMS 위치와 active 표시 기준을 정리했다.

## KMS 홈 UI 개선

- 요약 카드를 동일 높이 카드로 정리하고 보조 설명을 추가했다.
- 태그 통합 검색 패널에 설명, 인기 태그, 선택 태그, 검색 결과 영역을 명확히 분리했다.
- 대분류 카테고리 카드는 metric grid, 대표 태그 chip, 마지막 수정일을 한 카드 안에서 읽을 수 있게 정리했다.
- 최근 작성/수정 및 복습 필요/실전 적용 후보 영역에 빈 상태 안내를 추가했다.

## 태그 검색 UX 개선

- 쉼표 기반 입력 안내를 추가했다.
- 선택 태그 chip에 제거 표시를 추가했다.
- 선택 태그가 없거나 검색 결과가 없을 때 안내 문구를 표시한다.

## 지식 게시판 UI 개선

- 좌측 카테고리 필터를 독립 카드형 패널로 정리했다.
- 검색창, 학습 상태, 중요도, 검색, 초기화 버튼을 한 필터 바에 정렬했다.
- 게시글이 없을 때 빈 상태 카드와 `새 지식 등록` 버튼을 표시한다.
- 게시글 카드 제목/요약은 긴 텍스트에서 레이아웃이 깨지지 않도록 제한했다.

## 게시글 상세/등록 화면 개선

- 필수 입력 필드에 `*` 표시를 추가했다.
- 태그 입력 안내를 추가했다.
- 상세 화면은 요약, 본문, 메타 정보 영역을 분리했다.
- 본문은 줄바꿈을 유지하는 `pre-wrap` 표시를 유지한다.

## KMS 설정 UI 개선

- 카테고리 목록을 compact list item 형태로 정리했다.
- 선택된 카테고리는 좌측 accent bar로 강조한다.
- 활성/비활성 표시는 작은 badge로 축소했다.
- 신규 입력 상태 안내와 표시 순서 숫자 검증을 추가했다.

## 메뉴 위치 조정

좌측 대메뉴 순서를 다음 기준으로 조정했다.

- 투자 전략
- 시장 트렌드 분석
- 종목 관리
- 정보 수집
- 매매 관리
- DrCT KMS
- 시스템

## Active Menu 버그 수정 기준

- `/kms`, `/kms/`: KMS 홈만 active
- `/kms/posts`, `/kms/posts/:postId`: 지식 게시판 active
- `/kms/settings`: KMS 설정 active

KMS 메뉴에 한해 exact/prefix 판정을 명시적으로 분리했다.

## 기존 기능 영향 여부

이번 작업은 프론트 UI/메뉴/라우팅 중심 보완이다. DB, backend API, 기존 KMS 테이블, 기존 매매관리/시스템 기능은 변경하지 않았다. `TradeTrainingPage.tsx`도 변경하지 않았다.
