# 59-C-1 물가/경기 차트 화면 연동 결과

## 적용 범위
- 시장 지표 상단 필터에 `물가/경기` 그룹을 추가했다.
- `CPI`, `PPI`, `CSI`, `BSI_MANUFACTURING`을 일반 시장지표 목록과 비교 그룹에 포함했다.
- 기존 `금리/환율` 그룹은 환율/금리 지표만 표시하도록 분리했다.
- `전체` 그룹에서는 주식시장 지표와 금리/환율, 물가/경기 일반 지표를 함께 조회할 수 있다.

## 차트 연동
- 월간 일반 지표는 기간 버튼을 `6M / 1Y / 3Y / 5Y / ALL`로 전환한다.
- 월간 지표의 기본 기간은 기존 기간이 월간 옵션에 없을 때 `5Y`로 보정한다.
- CPI/PPI는 기존 라인 차트로 1차 표시하고, 요약 영역과 목록 카드에 MoM/YoY를 표시한다.
- CSI/BSI는 `LINE_WITH_BASELINE` 타입일 때 `base_line_value` 기준선을 차트에 표시한다.
- 비교 차트에는 `물가/경기` 패널을 추가했고, 기존 비교 방식과 동일하게 첫 관측값 100 기준으로 정규화한다.
