# DrCT 종목 시그널 Phase 6-C.3 — 사용자 친화 추천기준 UX와 반자동 개선

## 1. 사용자용 UX 원칙

사용자는 통계 용어를 해석하지 않고도 성공 학습 수, 현재 후보 수, 후보 범위, 엄격 기준 후보 수와 실제 차트를 확인할 수 있어야 한다. 기본 화면은 사용자용 설명에 집중하고, 분포는 `세부 비교 보기`, 계산식과 버전은 `알고리즘 상세`에 배치한다.

## 2. 전문용어 제거 Mapping

| 기술 표현 | 기본 화면 표현 |
|---|---|
| 패턴 판별력 검증 | 추천 기준 점검 |
| S LOO | 과거 성공 사례 |
| Current Universe | 현재 분석 종목 |
| P25 / Median / P75 / P90 | 넓게 / 기본 / 엄격 / 매우 엄격 |
| Threshold Simulation | 추천 범위 비교 |
| Eligible Marker | 적용 Marker |
| Multiple Marker | 복수 패턴 종목 |
| Median/P75 Gap, Candidate Pair | 알고리즘 상세에서만 표시 |

## 3. 유사도 기준 25/50/75/90

- 넓게(25): 과거 성공 사례의 넓은 범위까지 포함한다. 현재 운영 기준이다.
- 기본(50): 과거 성공 사례의 중간 수준을 기준으로 한다.
- 엄격(75): 성공 사례 중 더 닮은 종목을 중심으로 본다.
- 매우 엄격(90): 매우 강하게 닮은 종목만 본다.

화면 선택은 비교용이며 운영 기준이나 DB 값을 변경하지 않는다.

## 4. 자동학습

Scan은 실행할 때마다 최신 성공(S) 사례와 수동 `학습 제외` 결정을 조회해 Signature, 성공 사례 유사도 기준, 현재 후보와 추천 범위 비교를 다시 계산한다. 별도 재학습 버튼이나 Scheduler를 추가하지 않는다.

## 5. 자동 개선 SHADOW

`CANDIDATE_POLICY_SHADOW_V1`은 다음 두 조건을 동시에 만족하는 후보를 연구용으로 계산한다.

1. 과거 성공 사례 기준 25 이상
2. 현재 분석 종목 유사도 분포의 상위 10% 기준 이상

따라서 실제 임계값은 `max(성공 사례 기준 25, 현재 분석 종목 기준 90)`이다. 이는 넓은 Marker를 현재 시장에서도 상대적으로 강하게 닮은 사례로 좁힐 수 있는지 확인하는 결정적이고 재현 가능한 정책이다.

## 6. 운영 기준 불변

운영 정책은 `CANDIDATE_POLICY_BASELINE_V1`이며 기존 성공 사례 기준 P25를 그대로 사용한다. 실제 DB 기준 운영 결과는 224 Pair, 142종목으로 Phase 6-C.2와 동일하다. SHADOW V1은 64 Pair, 중복 제거 47종목, 복수 패턴 15종목이지만 운영 후보에는 포함하거나 대체하지 않는다.

| Marker | 성공 학습 | 현재 후보 | 범위 | 기준 25/50/75/90 | SHADOW 후보 | 상태 |
|---|---:|---:|---|---|---:|---|
| 전고점 / 매물대 | 7 | 7 | 선별적 | 7 / 4 / 2 / 1 | 7 | 현재 기준에서도 선별적 |
| 전저점 / 전Box상단 | 5 | 141 | 매우 넓음 | 141 / 121 / 10 / 10 | 19 | 패턴 개선 검토 |
| 하락 추세Box 상단 저항 | 5 | 40 | 넓음 | 40 / 0 / 0 / 0 | 19 | 엄격 기준에서 크게 감소 |
| 삼각수렴 깨짐 | 5 | 36 | 넓음 | 36 / 36 / 8 / 4 | 19 | 엄격 기준에서 크게 감소 |

후보 범위 UX 기준은 평가 가능 종목 대비 비율로만 계산한다: `5% 이하 선별적`, `15% 이하 적당함`, `35% 이하 넓음`, `35% 초과 매우 넓음`. 이는 추천 성능이나 투자 판단 등급이 아니다.

## 7. 구조적 Algorithm 변경 정책

Feature 수, Distance Formula, Weight, Shape Feature, Similarity Formula는 자동 변경하지 않는다. 구조적 변경은 새 버전으로 만들고 운영 버전과 SHADOW 비교, 실제 성과 검증, 명시적 승격 절차를 거친다.

## 8. 사용자 개입 범위

사용자는 기존과 같이 애매한 성공 사례를 `학습 유지` 또는 `학습 제외`로 검토한다. Threshold, Feature Weight, Algorithm Version을 직접 저장하거나 조정하는 기능은 제공하지 않는다.

## 9. 향후 Shape V2 구조

SHADOW 기준에서도 실제 차트 구분이 어려우면 D-20~D0 정규화 종가, High/Low 구조, MA5/10/20/60 흐름, 거래량 흐름을 사용하는 Shape Feature V2를 별도 SHADOW 버전으로 연구한다. 이번 Phase에서는 Shape Feature를 구현하지 않는다.

## 10. 비저장 정책

추천 범위 비교, 분포, SHADOW 후보, 임계값, Feature Matrix, 검토 결과는 모두 Runtime 전용이다. 신규 테이블과 Migration이 없고, API는 명시적 집계 필드와 제한된 화면 검토 샘플만 반환한다. Search, F, Outcome은 현재 후보 및 SHADOW 계산에 사용하지 않는다.
